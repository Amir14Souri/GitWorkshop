# Git Workshop

A comprehensive workshop covering essential Git concepts and commands for version control, collaboration, and workflow management.

+ Workshop (https://github.com/Amir14Souri/GitWorkshop/raw/main/Slides.ppsx)[Slides]
+ Workshop (https://s15.uupload.ir/files/forati/ap-sut/Workshops/Git.mp4)[Video] in persian

## Topics Covered

1. **What is Git?** - Version Control Systems (VCS), versioning, teamwork
2. **Primary Commands** - init, config, status, log, add, rm, commit, diff
3. **Environment** - Terminal, VS Code, IntelliJ IDEA
4. **Branch & Merging** - branch, checkout, merge, rebase, conflict resolution
5. **Undoing Changes** - restore, revert, reset, reflog, interactive rebase
6. **Remote** - GitHub/GitLab/Gitea, remote, SSH/HTTPS, fetch, pull, push, PR/MR, clone
7. **File Management** - .gitignore, .gitkeep, stash, filter-branch
8. **Versioning** - tags, releases
9. **Config** - local/global/system config, aliases, credential helpers, proxies
10. **Visualization Tools** - learngitbranching.js.org, tig, GitHub Desktop, IDE integrations, Oh My Zsh/Fish

## Prerequisites

- Install Git: [https://git-scm.com/install/](https://git-scm.com/install/)

## Common Errors Covered

- Forgotten files on last commit
- Committing to wrong branch
- Accidental `git reset --hard`
- Detached HEAD state
- Rejected pushes
- Credential/large file leaks
- Authentication errors
